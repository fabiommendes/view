# Projeto de exemplo

Um projeto pequeno para testar o visualizador de markdown.

## Instalação

1. Clone o repositório.
2. Rode `cargo build`.
3. Execute o binário.

## Recursos

- Leitura de arquivos locais
- Suporte a URLs
- Cabeçalho com o comando equivalente

| Formato | Backend     |
| :------ | :---------- |
| md      | glow        |
| json    | bat         |

Veja a [documentação oficial](https://example.com/docs) para mais detalhes.

```sh
view README.md
```

> Testes manuais valem mais que suposições.
